# reading-tracker
Habit tracker that visually represents your progress using Pixela

Features
- Prompts users to enter a book title, author, and number of pages read.
- Records daily reading activity using the Pixela API.
- Stores book titles and authors as additional metadata for each reading entry.

Technologies
- Python
- Libraries: Requests, Pixela API, Datetime

What I Learned:
- Using Pixela API
- Posting requests
- Using headers
